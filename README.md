> **Enable the snake animation + private commits:** GitHub's servers can't read your private contribution squares from a public embed — that data has to be generated *by you*, from your own account, via a scheduled Action. Add the workflow below to this repo (`zynx095/zynx095`) once, and both the streak stats and the snake graphic above will include private commits automatically going forward.

<details>
<summary><strong>⚙️ .github/workflows/snake.yml (click to expand)</strong></summary>

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */6 * * *"   # every 6 hours
  workflow_dispatch: {}
  push:
    branches: [ "main" ]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: zynx095
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

For the private-contribution *stats* (streak, activity graph) to include private repos too, also set `count_private=true` (already in the URLs above) — that flag alone works for public stats sourced from the GitHub API, no extra secret needed, as long as "Private contributions" is turned on under **Settings → Profile → Contributions** on your GitHub account.

</details>
